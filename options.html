Workflows

Pick the one to use with the circle. You can also switch from the toolbar icon. Importing a file with the same name replaces the old one.

Preparing a workflow

  1. In ComfyUI, double-click the node that should receive your input and rename its title to INPUT_TEXT (a text prompt node) or INPUT_IMAGE (a Load Image node).
  2. Use Workflow > Export (API) to save the file, then import it above.
